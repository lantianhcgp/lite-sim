fix: 画布容器宽 0 导致图标全部挤出画布（红圈问题根因）

用户截图圈 4 处：候选词区、底栏左右空白、右下白色区、日志警告。

根因（坐标铁证，?debug=1 逐元素 rect）：
  修复前 <div im-bottom-tab-container> x=0..0 (0x54)  ← 宽 0
         <img> x=-171..-123                              ← 图标在画布外
  修复后 x=0..412、img x=23..71                          ← 全部归位

CSS 链断裂点：
  #stage (flex column + align-items:center)
    → #frameWrap { position:relative; background:#fff }   ← 没有宽度
      → #frame { width:100%; max-width:412px }            ← 后一条规则覆盖 width:412px
        → #screen { position:absolute; inset:0 }          ← 归零
          → 所有 width:100% 子元素全链解析为 0

align-items:center 会让 flex item 按内容收缩，而 #frame 要 100% 父宽、
#frameWrap 要靠内容定宽 —— 循环依赖塌缩成 0。子元素因 width:0 而溢出，
图标被挤到负坐标（x=-171），底栏只剩 input 单独居中。

修：#frameWrap 加 width:412px;max-width:100%

同时修第二个 bug：hml 的 style 属性里常见
  background-color: {{ RounderBackgroundValue.background }}
_applyAttrs 对 style 直接 push 字符串不求值 → 整条声明无效 →
图标容器背景透明、圆角丢失（图上看不到深色背景块）。
→ style 也走 _bindStr() 求值
